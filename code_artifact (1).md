# Специфікація полів, статусів та правил відображення для Бота (гілка `stage`)

Цей документ структурує сутності, їхні базові та умовні поля, а також доступні статуси на основі бізнес-документації. Його можна використовувати для побудови покрокових екранів (сторінок), діалогів або WebApp-форм у боті.

---

## 1. Ерайв / Вантаж (`Arrive` / `Cargo`)
**Джерело:** `cargo/BUSINESS.md` та фактична таблиця «Вантажі» (`cargo-registry.html` / `warehouse.js`)

Сутність описує фактичне надходження вантажу на склад та відображення у реєстрі вантажів. Поля структуровані відповідно до актуального реєстру/таблиці та можуть бути розбиті на логічні кроки/сторінки бота.

### 1.1. Ідентифікатори та прив’язки до сутностей
* **DF номер Обіцянки** (`df_promise` / `dfPromise`) — посилання/прив'язка до сутності Обіцянка.
* **DF номер ерайва** (`arrive_number` / `id`) — унікальний ідентифікатор вантажу/ерайву.
* **Трек-номер** (`tracking_number` / `trackNumber`) — трек-номер вантажу.
* **DF номер перевезення** (`related_transportation` / `dfShipment`) — посилання/прив'язка до сутності Перевезення.
* **Клієнт** (`client`) — клієнт / замовник перевезення.
* **Підрейс** (`subvoyage` / `subvoyage_id`) — прив'язка до підрейсу.

### 1.2. Статуси, задачі та ознаки
* **Статус** (`status`) — поточний стан вантажу.
* **Тип вантажу** (`cargo_type` / `isCargo`) — ознака типу (наприклад, Карго / Не Карго).
* **Закрити Док. експортеру** (`close_docs_exporter` / `closeDocsExporter`) — прапорець/статус закриття експортних документів.
* **Задачі** (`tasks`) — наявність та статус складських/логістичних завдань по вантажу (кількість активних / завершених).

### 1.3. Логістика, локація та дати
* **Склад** (`warehouse`) — склад приймання / поточного знаходження.
* **Дата прибуття** (`arrival_date` / `arrivalDate`) — дата прибуття вантажу.
* **Дата отримання** (`receive_date` / `receiveDate`) — дата фактичного отримання.
* **Створено / Завантажено** (`created_status` / `createdStatus`) — статус/дата створення або завантаження.
* **Відправлення** (`origin`) — пункт або країна відправлення.
* **Прибуття** (`destination`) — пункт або країна призначення.
* **Спосіб перевезення** (`transport_mode` / `mode`) — авіа, море, наземний транспорт тощо.

### 1.4. Опис та номенклатура вантажу
* **Назва товару (укр)** (`name_ua` / `titleUa`) — україномовна назва.
* **Назва товару (кит)** (`name_zh` / `titleCn`) — китайськомовна назва.
* **Назва товару (англ)** (`name_en` / `titleEn`) — англомовна назва.

### 1.5. Габарити, вага та пакування
* **Кількість місць** (`places_count` / `places`) — кількість вантажних місць (шт).
* **Вага брутто** (`gross_weight` / `weight`) — фактична вага брутто (кг / т).
* **Об’єм** (`volume`) — фактичний об'єм вантажу ($m^3$).
* **Негабарит (коментар)** (`is_oversized`, `oversize_comment` / `oversizeComment`) — ознака негабаритності та коментар/розміри.
* **Тип пакування** (`packaging_type` / `packageType`) — вид пакування (коробка, дерев'яний ящик, палета тощо).

### 1.6. Додаткові сервіси, коментарі та медіа
* **Додаткові послуги** (`additional_services` / `extraServices`) — додаткові складські послуги (маркування, перепакування тощо).
* **Відповідальний менеджер** (`responsible_manager` / `manager`) — менеджер, закріплений за вантажем/клієнтом.
* **Відповідальний логіст** (`responsible_logist` / `logist`) — закріплений логіст.
* **Примітка логіста** (`logist_note` / `logistNote`) — коментар/примітка логіста.
* **Посилання на фото / Фотофіксація** (`photo_links` / `photoUrl`, `photoStages`) — посилання на фотографії або етапи фотофіксації.

### 1.7. Довідник статусів Вантажу (Ерайву)

| Код (`status`) | Назва |
| :--- | :--- |
| `new` | Новий |
| `at_origin_warehouse` | На складі відправки |
| `received_unmarked` | Отримано непромаркованим |
| `transferred_to_logistician` | Передано |
| `transfered_to_logistician_for_marking` | Передано логісту на маркування |
| `storaging_in_warehouse` | Зберігання на складі |
| `waiting_for_other_parts` | Очікує інші частини |
| `awaiting_readiness` | Очікує готовності |
| `ready_for_loading` | Готовий до завантаження |
| `in_transit` | В дорозі |
| `at_destination_warehouse` | На складі призначення |
| `issued` | Виданий |
| `returned_to_customer` | Повернено клієнту |
| `waiting_for_task_execution` | Очікує виконання завдання по вантажу |

## 2. Перевезення (`Transportation`)
**Джерело:** `transportations/BUSINESS.md`

Сутність має розгалужену логіку, яка залежить від способу доставки, маршруту та специфіки вантажу.

### 2.1. Базові поля (відображаються завжди)
* **Клієнт** (`client`)
* **Статус** (`status`)
* **Маршрут (базовий):**
  * Країна та адреса відправлення (`origin_country`, `origin_address`)
  * Країна та адреса призначення (`destination_country`, `destination_address`)
* **Відправлення:**
  * Спосіб доставки (`delivery_method`)
  * Контактні дані відправника (`sender_contacts`)
  * Дата готовності вантажу (`cargo_ready_date`)
* **Параметри логістики та митниці:**
  * Спосіб перевезення (`transport_mode`)
  * Тип перевезення (`transport_type`)
  * Тип завантаження (`loading_type`)
  * Митне оформлення (`customs_clearance`)
  * Митні умови (`customs_terms`)
  * Додаткові параметри доставки (`additional_delivery_params`)
* **Специфіка небезпеки:**
  * Небезпечний вантаж (`dangerous_goods` — так/ні/клас)
  * Наявність батарей (`batteries` — так/ні/тип)

### 2.2. Варіативний блок: Параметри вантажу (АБО / АБО)
Залежно від деталізації заявки обирається один із варіантів:
* **Варіант А (Деталізований):** Перелік товарів (`items_list`).
* **Варіант Б (Загальний/Плановий):**
  * Планова кількість місць (`planned_places`)
  * Планова вага (`planned_weight`)
  * Плановий об’єм (`planned_volume`)

### 2.3. Умовні поля (Залежно від маршруту та етапів доставки)
Ці поля підтягуються динамічно, якщо маршрут передбачає складську обробку, кур'єрський забір або доставку до дверей:
* **Адреса складу** (`warehouse_address`) — *якщо маршрут проходить через транзитний/консолідаційний склад.*
* **Номер накладної** (`waybill_number`) — *при відправленні локальними службами або наявності супровідної накладної.*
* **Дані кур’єра** (`courier_details`) — *якщо обрано кур'єрський забір/доставку.*
* **Дані останньої милі** (`last_mile_details`) — *якщо на фінальному етапі залучений локальний перевізник.*

### 2.4. Основні статуси Перевезення

| Код (`status`) | Назва |
| :--- | :--- |
| `unprocessed` | Необроблений запит |
| `tariff_request` | Запит на тариф |
| `tariff_added` | Додано тариф |
| `tariff_sent` | Відправлено тариф клієнту |
| `tariff_lost` | Програно тариф |
| `awaiting_warehouse` | Очікується на складі |
| `partially_received` | Частково отримано на складі |
| `received_at_warehouse` | Отримано на складі |
| `broker_recalculation` | Перерахунок брокера |
| `tariff_under_review` | Тариф на узгодженні |
| `ready_for_loading` | Готовий до завантаження |
| `unloaded` | Вивантажено на складі призначення |
| `ready_for_pickup` | Готовий до видачі |
| `last_mile` | Остання миля |
| `received` | Завершено |
| `cargo_issues` | Проблеми з вантажем |
| `rejected` | Відхилено |
| `self_pickup_completed` | Видано отримувачу |

## 3. Підрейс (`Subflight`)
**Джерело:** `subflights/BUSINESS.md`

Сутність має чіткий поділ на загальні поля та специфічні блоки залежно від обраного **Способу перевезення**.

### 3.1. Базові поля (спільні для всіх підрейсів)
* **Ідентифікація та налаштування:**
  * Назва (`name`)
  * Зовнішній рейс (`external_flight`)
  * Шаблон (`template`) — **визначає набір доступних статусів**
  * Статус (`status`)
  * Спосіб перевезення (`transport_mode`) — **ключовий тригер для умовних полів нижче**
  * Відповідальний логіст (`responsible_logist`)
* **Ознаки (чекбокси/прапорці):**
  * «Основний» (`is_main`)
  * «Транзит» (`is_transit`)
* **Географія та точки:**
  * Країна відправлення (`origin_country`)
  * Країна доставки (`destination_country`)
  * Місце завантаження (`loading_place`)
  * Місце розвантаження (`unloading_place`)
* **Таймінг та нотатки:**
  * Планові дати (`planned_dates` — виліт/виїзд та прибуття)
  * Фактичні дати (`actual_dates` — виліт/виїзд та прибуття)
  * Коментар (`comment`)

### 3.2. Умовні поля (Залежно від значення «Спосіб перевезення»)

| Спосіб перевезення | Додаткові поля форми (Сторінка специфіки) |
| :--- | :--- |
| 🚢 **Морський (`Sea`)** | • Порти (відправлення / призначення)<br>• Морська лінія (`shipping_line`)<br>• Номер бронювання (`booking_number`) |
| ✈️ **Авіа (`Air`)** | • Аеропорти (вильоту / прильоту)<br>• Авіалінія (`airline`)<br>• Номер AWB (`awb_number`) |
| 🚚 **Наземний (`Land` / `Road` / `Rail`)** | • Прикордонний пункт (`border_crossing`)<br>• Місця митного оформлення (`customs_clearance_places`) |

### 3.3. Статуси Підрейсу (Стани шаблону)
> **Примітка:** У Підрейсу немає одного спільного списку статусів — доступні статуси залежать від вибраного шаблону (`template`). Нижче наведено стани шаблону, які описані в гілці `stage`.

| Стан (`status`) | Назва |
| :--- | :--- |
| `formation` | Формування |
| `packed` | Завантажений |
| `in_transit` | В дорозі |
| `despatched` | Вивантажений |
| `completed` | Завершений |
| `at_export_customs` | На митниці на експорт |
| `at_import_customs` | На митниці на імпорт |
| `cargo_released_to_recipient` | Вантаж видано отримувачам |

## 4. Рекомендації щодо розбиття на сторінки (Екрани) для Бота

Щоб не перевантажувати користувача в інтерфейсі бота, рекомендується така логіка переходів:

1. **Створення/редагування Підрейсу:**
   * **Екран 1 (Базовий):** Назва, Зовнішній рейс, Шаблон, Статус, Логіст, Ознаки («основний», «транзит»), **Спосіб перевезення**.
   * **Екран 2 (Маршрут і специфіка):** Країни, місця завантаження/розвантаження + *автоматичне підвантаження полів для Моря / Авіа / Землі*.
   * **Екран 3 (Дати і фінал):** Планові/фактичні дати, Коментар.

2. **Створення/редагування Перевезення:**
   * **Екран 1 (Клієнт і Маршрут):** Клієнт, Статус, країни та адреси, спосіб доставки, контакти відправника.
   * **Екран 2 (Логістика і Митниця):** Спосіб і тип перевезення, тип завантаження, митне оформлення та умови, дата готовності.
   * **Екран 3 (Вантаж і Безпека):** Перемикач «Товари списком» АБО «Планові габарити», прапорці небезпеки та батарей.

3. **Створення/редагування Ерайву / Вантажу:**
   * **Екран 1 (Ідентифікатори та зв'язки):** DF номер Ерайву, DF номер Обіцянки, DF номер Перевезення, Трек-номер, Склад, Клієнт, Підрейс.
   * **Екран 2 (Статуси та логістика):** Статус, Тип вантажу (Карго/Не Карго), Закрити Док. експортеру, Спосіб перевезення, Пункти Відправлення та Прибуття, Дата прибуття / отримання.
   * **Екран 3 (Номенклатура та габарити):** Назви товару (УКР, КИТ, АНГЛ), Кількість місць, Вага брутто, Об'єм, Негабарит (ознака та коментар), Тип пакування.
   * **Екран 4 (Відповідальні, послуги та медіа):** Відповідальний менеджер, Відповідальний логіст, Примітка логіста, Додаткові послуги, Посилання на фото / Фотофіксація, Задачі.
